The mission

Less setup.
More time playing.

Switching between a main mod, its submods, and patches can mean rebuilding launch arguments every time. This project gives each setup a name and a place to save it.

The goal is a practical, portable manager that makes your library easier to understand and your favorite setups easier to revisit.

  • Simplify the routineReduce repeated setup with reusable presets and clear launch controls.
  • Make the order clearKeep mod order visible and let players follow each author’s instructions.
  • Keep players in controlCustomize your library while keeping installed mod files untouched.
  • Explain problemsReport missing mods and scan issues so players can see what needs attention.
  • Stay portableKeep preferences locally, with no installer required for the packaged release.
Your first launch

From library to campaign.

Start with the packaged Windows x64 release ZIP. Extract all files into a writable folder and keep them together.

  1. Open the manager. Run EmpireModManager.exe from the extracted folder.
  2. Check your folders. Use Folders to confirm your game installation and Workshop locations.
  3. Create a preset. Choose Empire at War or Forces of Corruption, then add your installed mods.
  4. Arrange and launch. Follow the authors’ load order, then choose Save & launch preset.

Before you begin

  • A Windows x64 PC.
  • An installed copy of the game and the expansion your preset requires.
  • Installed mods for your chosen setup.
  • Steam running when launching the Steam edition.

The release package includes the .NET runtime. Internet access is needed to refresh Workshop metadata; local discovery and cached details work offline.

The game and mods are not included. An empty preset launches the unmodded game.

Good to know

A few details before launch.

Does the manager download or update mods?

It manages mods already installed on your PC. Steam handles Workshop subscriptions and updates. Install local mods using their authors’ instructions, then rescan your library.

Can I combine any mods in a preset?

Compatibility depends on the mods. The manager does not merge mod files or automatically resolve dependencies. Use combinations and launch orders supported by the mod authors. A valid launch command does not guarantee that every mod loaded correctly in game.

Where are my presets and settings saved?

They are stored in the data folder beside the executable. Back up that folder before updating or moving the app. Presets do not provide separate game saves or game-settings profiles.

Can I build the project from source?

Yes. The application uses C#, .NET 9, and Windows Forms. On Windows with the .NET 9 SDK, run dotnet build -c Release. See the development guide for packaging and checks.
